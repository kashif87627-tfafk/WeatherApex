🌦️ WeatherApp — Android Weather Application

WeatherApp is a simple yet powerful Android application that provides real-time weather information based on the user’s current GPS location or a searched city name. It’s designed with a clean UI, smooth navigation, and dynamic visuals that adapt to the current weather conditions.

🚀 Features

Real-Time Weather Data — Fetches current weather details (temperature, humidity, wind speed, etc.) using OpenWeatherMap API.

Location-Based Updates — Automatically detects the user’s location using GPS for instant local weather.

City Search Option — Users can manually search for any city to view its weather conditions.

Dynamic Backgrounds — Background changes automatically according to the weather type (sunny, rainy, cloudy, etc.) for a more immersive experience.

Responsive UI — Optimized for various Android screen sizes and orientations.

🧭 How It Works

Launch the App — The app requests location permission and retrieves the user’s current GPS coordinates.

Fetch Weather Data — Uses the coordinates or searched city name to fetch weather data from the OpenWeatherMap API.

Display Results — Weather details are displayed on a separate result screen, along with a weather-themed background.

🛠️ Tech Stack

Language: Java / Kotlin

IDE: Android Studio

API: OpenWeatherMap API

Location Services: Android Location Manager / Fused Location Provider

UI: XML layouts with dynamic drawable backgrounds

📷 Screens

Home Screen: Search bar + GPS detection button

Weather Result Screen: Displays temperature, weather type, humidity, and wind speed with background animation
